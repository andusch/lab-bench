# Export Markdown

Status: done

## Problem

The student can see the fit numbers, and the lab report has no text file of those numbers.

## Outcome

Tauri writes a Markdown file for the fit from P1-03. The file lists the degree, each coefficient with its standard error, and R^2.

## Acceptance

- The file names the degree.
- Each coefficient appears with its standard error.
- R^2 appears once.
- The file has no covariance matrix.

## Tests

- Export the Hooke's law degree-1 fit and read the slope, its standard error, and R^2 from the file.
- Export a capacitor fit and confirm the file has no time constant.

## Non-goals

- Typst.
- PDF.
- A covariance matrix.
