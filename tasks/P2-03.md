# Package LabBench for macOS

Status: done

## Problem

A student on a Mac has no disk image that installs the desk.

## Outcome

`npm run tauri build` on a Mac writes a disk image and `LabBench.app`. `src-tauri/tauri.conf.json` already lists `icons/icon.icns`, and `bundle.targets` is already `"all"`. Opening the disk image and copying LabBench to Applications installs the P1 desk.

## Acceptance

- `npm run tauri build` finishes on macOS, and `bundle.targets` is still `"all"`.
- On Apple Silicon the build writes `src-tauri/target/release/bundle/dmg/LabBench_0.1.0_aarch64.dmg`.
- On an Intel Mac the build writes `src-tauri/target/release/bundle/dmg/LabBench_0.1.0_x64.dmg`.
- The disk image contains `LabBench.app`.
- Copying that app to Applications and launching it opens the desk with no dev server.
- The installed desk fits `samples/hookes-law.csv` at degree 1 with a slope between 17.5 and 18.5 N/m.
- A fit of `samples/capacitor-discharge.csv` has no time constant.

## Tests

- Run `npm run tauri build` on a Mac and confirm the `.dmg`.
- Open the disk image, copy LabBench to Applications, and fit Hooke's law at degree 1.
- Fit the capacitor sample and confirm the result has no time constant.
