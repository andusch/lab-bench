# Package LabBench for Windows

Status: not done

## Problem

A student on Windows has no setup program that installs the desk.

## Outcome

`npm run tauri build` on Windows writes the NSIS setup program and the MSI. `src-tauri/tauri.conf.json` already lists `icons/icon.ico`, and `bundle.targets` is already `"all"`. Running the setup program installs the P1 desk. The installed LabBench opens with no console window.

## Acceptance

- `npm run tauri build` finishes on Windows, and `bundle.targets` is still `"all"`.
- On a 64-bit PC the build writes `src-tauri/target/release/bundle/nsis/LabBench_0.1.0_x64-setup.exe`.
- That build also writes `src-tauri/target/release/bundle/msi/LabBench_0.1.0_x64_en-US.msi`.
- Running the setup program installs LabBench. Launching it opens the desk with no dev server and no console window.
- The installed desk fits `samples/hookes-law.csv` at degree 1 with a slope between 17.5 and 18.5 N/m.
- A fit of `samples/capacitor-discharge.csv` has no time constant.

## Tests

- Run `npm run tauri build` on Windows and confirm the setup `.exe` and the `.msi`.
- Install from the setup `.exe`, open LabBench, and fit Hooke's law at degree 1.
- Confirm the window has no console behind it.
- Fit the capacitor sample and confirm the result has no time constant.
